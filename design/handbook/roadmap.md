# 当前路线图

## 1. 文档治理

私有文档仓库、current owner、ADR、活动任务、自动检查和旧资料脱敏归档已经建立；后续工作是随产品变更维护 owner，并从稳定产品路径继续提取 runbook。

## 2. Stardew 第一方玩家路径

完成安装发现、严格注册、双进程启动、AI client attachment、bootstrap containment、恢复、停止和可操作诊断。

## 3. 开放玩法循环

统一 adapter-owned action registration、运行时 catalog revision、typed Pi tools、fresh admission、原生 mutation、回执、postcondition 与 fresh observation。玩家 prompt 和真实终止事件定义任务寿命。

## 4. Chat 与 Tavern

完成 Chat lifecycle、内容管理、玩家可见 Memory、provider/model/credential preferences 和 fresh-root production UI 验收。

## 5. Desktop Player Release

完成 Windows shell、tray/WebView2、安装、升级、恢复和完整 onboarding。Browser Preview 仍是独立里程碑。

## 6. Voice 与陪玩体验

在真实 ASR/TTS 资产和设备路径闭合后完成语音与陪玩体验硬门。

## 后续方向

社区游戏 Connector、更多游戏集成和更开放的生态在第一方 Stardew vertical slice 稳定后分阶段推进。
